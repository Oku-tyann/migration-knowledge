## 1. タイ LTRビザ（Long-Term Resident Visa）概要

**制度概要:**  
タイ政府（BOI）が2022年に導入した10年長期滞在ビザ。富裕層・退職者・リモートワーカー・高度人材の4カテゴリーに対応。申請ポータル: [ltr.boi.go.th](https://ltr.boi.go.th/)

**公式ビザ費用:** 50,000バーツ（国内申請、10年マルチプルエントリー）

**2025年1月の条件緩和:**
- Wealthy Global Citizens：収入証明書の提出が不要に（資産証明のみで可）
- 複数カテゴリーで収入閾値が緩和

## 2. タイ LTRビザ：4カテゴリー詳細

| 医療保険 | 5万USD以上の保険加入 |

### カテゴリー②：Wealthy Pensioners（富裕層退職者）
| 条件項目 | 内容 |
|---|---|

| 年間所得（A） | 年金・配当・賃料等から8万USD以上 |
| 年間所得（B） | 4万〜8万USD ＋ タイへの25万USD投資 |
| 医療保険 | 加入必須 |

### カテゴリー③：Work-from-Thailand Professionals（リモートワーカー）
| 条件項目 | 内容 |
|---|---|
| 年間所得 | 過去2年間で年間8万USD以上 |
| 雇用形態 | 海外の企業に勤務するリモートワーカー |

## 4. バンコク・タイ：180日ルールとビザランの真実

### 「年間180日ルール」の誤解

| よくある誤解 | 実際のルール（2025年〜） |
|---|---|
| 「ビザなしで年間180日滞在できる」 | 180日は連続・累計上限の概念。ビザランで無限に延長できるわけではない |
| 「ビザランで何度でも30日リセットできる」 | **2025年より厳格化：ビザランは年間2回まで**に制限。3回以上は入国拒否リスク |
| 「陸路なら何度でも入れる」 | 陸路入国は特に厳格。出国後短期間での再入国は拒否されるケースあり |
| 「60日間ビザなし滞在できる」 | **2025年より航空路入国のビザなし滞在は30日に短縮** |

### オーバーステイ（不法滞在）の罰則

| オーバーステイ期間 | 罰金 | 再入国禁止期間 |
|---|---|---|
| 1日〜 | 500バーツ/日（上限20,000バーツ） | なし |
| 90日超 | 上限20,000バーツ | **1年間** |
| 1年超 | 上限20,000バーツ | **3年間** |
| 3年超 | 上限20,000バーツ | **5年間** |
| 5年超 | 上限20,000バーツ | **10年間** |

### 2025年以降の規制強化ポイント
- ビザランによる入国拒否：2025年初頭以降、数千人規模の入国拒否が発生
- ノービザ滞在期間：2025年より30日に短縮（従来の60日から変更）
- 陸路入国：年2回まで、各回30日を原則とする厳格運用に移行
- 長期滞在者には適切なビザ（LTR・タイランドプリビレッジ・非移民ビザ）の取得を強く推奨

## 6. マレーシア DE Rantauノマドパス

**制度概要:**  
MDECが運営するデジタルノマド向けプロフェッショナルビジットパス。外国企業からの収入で働くリモートワーカー向け。2022年ローンチ、2024〜2025年に要件が拡充。

| 項目 | 内容 |
|---|---|
| 滞在期間 | 12ヶ月（更新可、マルチプルエントリー） |
| 対象 | 18歳以上・マレーシア企業に雇用されていない外国人 |
| 申請場所 | オンライン申請（マレーシア在住不要） |
| 処理期間 | 通常2〜4週間 |
| 費用 | 約RM 1,440以上（USD 315以上）、保険・保証金別途 |
| 家族 | 配偶者・子・親同伴可（RM 540/人） |

### 収入要件（職種別）

| 職種 | 最低年収 |
|---|---|
| IT・デジタル人材 | USD 24,000/年（月2,000ドル） |
| 非IT（2024年拡充後）：創業者・CEO・会計士・法律専門家・ライター等 | USD 60,000/年（月5,000ドル） |

### 税制
- 外国源泉所得：**2026年12月まで非課税**（免税措置）
- マレーシア国内企業への就業は禁止

### 2025〜2026年の重要変更点
- 申請手数料は2025年5月以降**返金不可**
- 手続きの簡素化と対象職種の拡充（2024〜2025年）
- 2026年時点で世界最も申請しやすいノマドビザの一つと評価される

|---|---|

## 8. インドネシア（バリ島）E33G デジタルノマドビザ

**制度概要:**  
インドネシア政府が発行するリモートワーカー向けビザ（通称：E33G、正式名称：Visa Rumah Kedua Pekerja Jarak Jauh）。2024年4月1日ローンチ。バリ島を中心に人気。

| 項目 | 内容 |
|---|---|
| 滞在期間 | **1年間**（更新・再申請で最大5年） |
| 対象 | インドネシア国外の企業に雇用されたリモートワーカー |
| 収入条件 | 年収 USD 60,000以上（海外源泉） |
| 資金証明 | 3ヶ月連続で最低USD 2,000以上の銀行残高 |
| 最低年齢 | 18歳以上 |
| 申請不可国籍 | アフガニスタン・カメルーン・ギニア・イスラエル・コソボ・リベリア・ナイジェリア・北朝鮮・ソマリア |

### 費用

| 申請方法 | 費用 |
|---|---|
| 公式手数料のみ | 約USD 315（申請USD 150 ＋ KITAS登録USD 165） |
| エージェント利用 | USD 615〜920 |

### 重要な制限事項
- **インドネシア国内企業・クライアントへのサービス提供は厳禁**
- フリーランス（自営業）での申請は不可（雇用契約書が必須）
- 有効な健康保険加入が必須
- 実態上、「更新」は再申請・再入国が必要なケースが多い

### 2026年の重要動向
- バリ島でのE33G違反取締り強化：2026年4月15日〜 Dharma Dewata Immigration Patrol Task Force（約100名）がチャングー・ウブド・スミニャック・クロボカン・ウルワトゥ等でパトロール実施

### 税務リスク
- KITAS保有者はDay 1から税務上の居住者とみなされる可能性あり
- 「実質基準（substance-based）」により183日ルールの適用外となるケースに注意

## 14. 注意事項・最新動向まとめ（2026年7月時点）

### タイ関連
- ビザなし滞在が**60日→30日**に短縮（2025年〜、航空路入国）
- ビザランは**年2回まで**。それ以上は入国拒否リスク
- LTRビザ申請はオンライン（ltr.boi.go.th）のみ。処理期間4〜8週間
- **Thailand Privilege Bronze：2026年9月30日申請締め切り**

### ドバイ関連
- UAEの法人税（9%）は年収37.5万AED超から適用（2023年〜）
- フリーゾーン内の事業は引き続き優遇（条件付き）
- IFZAが最もコストパフォーマンスの高いフリーゾーンとして日本人に人気

### マレーシア関連
- DE Rantauの手数料は**2025年5月から返金不可**
- 外国所得の非課税措置は**2026年12月末まで**（要注意）

### インドネシア関連
- E33Gは**フリーランス（自営業）では申請不可**（雇用契約書が必須）
- バリ島での取締り強化中（2026年4月〜）。税務上のリスク（Day1居住者扱い）に要注意

### ジョージア関連
- 旧「Remotely from Georgia」プログラムは終了
- **2026年3月〜の労働法改正で就労権（Work Authorization）の取得義務化**
- 日本人はビザなしで365日滞在可能（引き続き有効）

### フィリピン関連
- DNVは2025年6月正式運用開始だが、相互主義要件の対象国リストが未公開
- 実際の申請審査は流動的（2026年3月時点）
