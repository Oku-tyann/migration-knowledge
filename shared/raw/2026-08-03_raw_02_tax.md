## 情報3: ドバイ法人税2023年改正とQFZP（適格フリーゾーン法人）の実態

- 出典: https://nexpert-law.com/web3/dubai_houjinzei/ / https://astravista-property.com/columns/uae-corporate-tax-freezone-exemption-2026 / https://socpa.world/column/japanuaehikaku/
- 信頼度: 高
- 内容:
  - 2023年6月1日より、UAE全域で法人税9%が導入（年間利益AED 375,000超が対象）
  - フリーゾーン法人がQFZP（Qualifying Free Zone Person）として0%税率を継続適用するには条件あり:
    1. 所得の大半がQualifying Activities（適格活動）から得られていること
    2. 財務諸表の年次監査が義務化
    3. 実質的な事業活動をUAE内で行っていること（Substance要件）
  - 日本人がよく行うビジネス類型（コンサルティング・仲介・オンライン販売・情報提供等）はQualifying Activitiesに該当しないケースが多く、QFZP適用除外となり9%課税になる可能性が高い
  - 年次監査コスト: 中小規模でも年間AED 3,000〜10,000（約12〜40万円）が追加費用として発生
  - UAE・日本間には租税条約なし（2026年8月時点）→日本のCFC税制上、UAEはトリガー税率（27.5%）を大幅に下回るため外国子会社合算税制の対象になりやすい

## 情報6: ジョージア法人設立・バーチャルゾーン制度（2025〜2026年）

- 出典: https://all-about.ge/tax_system/ / https://offshore-houjin.com/taxsavingknowledge/georgiaoffshore/ / https://finance-shikin.com/georgia.html / https://nomad-visas.com/country/georgia/

- 内容:
  - **標準法人税（CIT）**: 15%（利益分配時のみ課税。留保利益は0%）
  - **バーチャルゾーン（VZ）法人**: IT事業者がジョージア国外の顧客に提供するサービスは法人税0%・VATも0%。最も優遇された制度。

## 情報7: マルタ法人税制と実効税率5%の仕組み

  - **名目法人税率**: 35%（EU内最高水準）

  - **デメリット**: 還付申請のプロセスが複雑で専門家への委託が必要。ランニングコストが高め（年間€5,000〜20,000の維持費）

## 情報9: タイ 海外所得課税ルール2024年改正の実態（2025〜2026年）

- 出典: https://bangken.com/column/2024/0305-3041289/ / https://www.tkao.com/column/column-2025-34/ / https://kyujin.careerlink.asia/blog/thailand-personal-income-tax-guide-2026/ / https://www.yamada-partners.jp/global-report/th-report-240305
- 信頼度: 高
- 内容:
  - **2024年1月1日改正内容（Por.161/2566 & Por.162/2566）**:
    - 旧ルール: タイ居住者が海外所得を「稼得した同年中に」タイへ送金した場合のみ課税
    - 新ルール: 2024年1月1日以降に稼得した海外所得はいつ送金しても課税対象（年度に関わらず）
  - **居住者の定義**: 暦年（1〜12月）で180日以上タイ滞在→税務上の居住者
  - **非居住者（180日未満滞在）**: 海外所得の持ち込み課税対象外
  - **デジタルノマドビザ（DTVビザ）**:
    - 有効期間5年（1回の入国で最長180日、延長で+180日=合計最大360日）
    - 月収や財産要件あり（500万バーツ以上の資産等）
  - **改正後の実態**: タイ在住の日本人で海外からリモート収入がある場合、2024年以降の所得は送金時に個人所得税（累進5〜35%）が課税されうる
  - **節税スキームの崩壊**: 旧来の「前年稼得分の翌年送金で非課税」手法は2024年改正で完全に封じられた
  - **注意**: タイには現在、日本との租税条約あり→日本で課税された所得は外国税額控除の対象になりうるが、二重課税リスクは残る

## 情報10: タイ183日ルール・デジタルノマド実態（2025〜2026年）

- 出典: https://atsoho.com/blog/remote-work-kaigai-zeikin / https://www.thedigitalnomad.jp/digital-nomad/タイ-ノマド/ / https://thailand-privilege.a-and-aa.com/faq/tax.php
- 信頼度: 中
- 内容:
  - タイの「183日ルール」は実際には「**180日**ルール」（タイ税法は暦年180日以上で居住者）
  - 183日という数字は日本の非居住者判定基準との混同から広まったと見られる

  - **2026年の見通し**: 個人所得税控除制度改正が2026年所得（2027年申告）から適用予定

## 情報11: 日本の出国税（国外転出時課税制度）の条件と対策

- 出典: https://www.nta.go.jp/taxes/shiraberu/shinkoku/kokugai/01.htm / https://shiodome.co.jp/column/7730/ / https://tomorrowstax.com/knowledge/2025012013979/ / https://mac-g.co.jp/international-tax/column/102/
- 信頼度: 高（国税庁公式含む）
- 内容:
  - **制度名**: 国外転出時課税制度（2015年7月1日施行）
  - **課税対象者の条件（両方を満たす場合）**:
    1. 有価証券等の対象資産の合計額が1億円以上
    2. 国外転出日前10年以内に国内在住期間が合計5年超
  - **対象資産**: 上場・非上場株式、投資信託、匿名組合出資、未決済デリバティブ取引。NISA口座の有価証券も対象
  - **課税方式**: 出国時点で全て売却したとみなして含み益に課税
  - **税率**: 所得税15.315%（復興特別所得税含む）+ 住民税5% = 合計20.315%
  - **納税猶予制度**:
    - 納税管理人の届出を行い担保を提供する場合、最長5年間猶予（申請で最大10年延長可）
    - 猶予期間中に対象資産を売却すると猶予取消し→即時納税
  - **対策**: ①対象資産を1億円未満に抑えて出国、②出国前に含み損銘柄を売却して含み益と相殺、③贈与・相続を活用（ただし贈与相続にも適用あり）

## 情報12: CFC税制（外国子会社合算税制）の適用条件と日本人のリスク

- 出典: https://kokusaizeimusouken.com/cfc/ / https://socpa.world/column/tax-haven-2025/ / https://maro-kaikei.co.jp/tax-haven-rules-japan/ / https://www.jetro.go.jp/world/qa/04A-010814.html
- 信頼度: 高
- 内容:
  - **CFC税制（タックスヘイブン対策税制）とは**: 日本の居住者・法人が低税率国に設立した子会社等の所得を、日本の親会社の所得に合算して日本で課税する制度
  - **適用のための主要条件**:
    1. 日本居住者・内国法人等が外国法人の**株式を50%超**保有（直接・間接含む）
    2. 外国法人の**租税負担割合が27.5%未満**（トリガー税率）
  - **対象となりやすい国**: UAE（実効9%または0%）、ジョージア（VZ適用時0%）、BVI（0%）、エストニア（留保時0%）、ジブラルタル（10%）、マルタ（実効5〜10%）→いずれもトリガー税率27.5%を下回る
  - **適用除外（経済活動基準）**: 以下の全てを満たすと合算課税から除外:
    1. 事業基準: 株式保有・保険・船舶業等の受動的事業でない
    2. 実体基準: 事業に必要な固定施設を現地に有する
    3. 管理支配基準: 事業の管理・支配・運営が所在地で行われている
    4. 非関連者基準または所在地国基準: 主要取引が非関連者との取引
  - **「実体」の重要性**: ドバイに法人を設立してもオーナーが日本に居住して実態のない運営をしていると経済活動基準を満たさずCFC適用→日本で課税
  - **対策**: 本人が現地に移住して183日以上滞在し、日本の非居住者となることが根本的な解決策

## 情報13: 日本住民票を抜く最適なタイミングと1月1日ルール

- 出典: https://bs.taxlawyer328.jp/blog/moving-abroad/p12862/ / https://biz.moneyforward.com/establish/basic/81699/ / https://tominagablog.com/moving-out/
- 信頼度: 高
- 内容:
  - **住民税の課税基準**: 毎年**1月1日時点**の住所で判定される
  - **節税の鉄則**: 1月1日に日本に住所がない状態を作ること（1月1日より前に海外転出届を提出する）
  - **住民税は前年所得ベース**: 前年に大きな所得がある場合でも、1月1日に非居住者であれば翌年の住民税は課税されない
  - **具体的なタイミング**:
    - 最も効果的: **12月31日までに**海外転出届を提出し、日本非居住者の状態で新年を迎える
    - 手続き: 出国1ヶ月前を目安に市区町村へ海外転出届を提出（郵送可）
  - **1月2日以降の出国**: 1月1日時点で日本居住者扱いとなり、その年の住民税（前年所得ベース）が翌年6月から課税される
  - **住民税の税率**: 所得の約10%（均等割加算あり）
  - **所得税の非居住者判定**: 1年以上継続して海外に居住し日本に住所がない→非居住者。国外源泉所得は原則として日本では課税されない
  - **注意**: 住民票を抜いても日本に居住実態がある場合、税務署から「みなし居住者」として課税される可能性あり

## 情報14: 日本の非居住者化プロセスと租税条約の活用

- 出典: https://www.ht-tax.or.jp/sozoku-guide/overseas-migration-tax / https://www.digima-japan.com/knowhow/world/5182.php / https://xn--lzry29aa129ih01c.com/bpコラム/デジタルノマドと海外移住の税務問題解決法/
- 信頼度: 中
- 内容:
  - **非居住者となる条件**: 日本に住所がなく、かつ1年以上継続して日本外に居所を持つ
  - **非居住者後の日本源泉所得**: 日本国内で発生した所得（国内不動産収入・日本企業からの配当・利子等）は引き続き日本で源泉徴収あり（税率20.42%等）
  - **租税条約の活用**: 居住地国と日本の間に租税条約があれば源泉税率の軽減が可能（例: タイ・シンガポールとは条約あり）
  - **UAE（ドバイ）と日本**: 租税条約なし（2026年8月時点）→UAE居住者でも日本源泉所得への二重課税リスクが残る
  - **デジタルノマドの税務リスク**:
    1. 滞在国での居住者認定（183日超）による課税
    2. 日本での「みなし居住者」認定（生活の本拠が日本とみなされるケース）
    3. 法人のCFC税制適用
    4. PEリスク（永久的施設）：物理的所在地のある国で法人税課税される
  - **現地専門家への相談を強く推奨**: 複数国にわたる課税問題は国際税務専門の税理士・弁護士への相談が必須
